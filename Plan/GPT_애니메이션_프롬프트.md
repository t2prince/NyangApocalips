# GPT 애니메이션 시트 생성 프롬프트

ChatGPT(이미지 생성)에 아래 순서로 요청한다.
**참고 이미지 2장을 꼭 첨부할 것**: `Cats/cat5.png` (원안 손그림 시트) + `Plan/_ref_style.png` (현재 게임 스타일).

결과물은 시트마다 아래 이름으로 저장 → `Plan/cat_frames5/` 에 넣는다:

| 파일명 | 내용 |
|---|---|
| `normal_idle.png` | 냥이 대기(춤) |
| `normal_walk.png` | 냥이 걷기 |
| `normal_jump.png` | 냥이 점프 |
| `normal_attack.png` | 냥이 냥냥펀치 |
| `laser_idle.png` / `laser_walk.png` / `laser_jump.png` / `laser_attack.png` | 레이저냥이 4종 |

다 넣은 뒤 Claude에게 "변환해줘"라고 하면 게임에 적용된다
(`python scripts/rebuild_anim.py Plan/cat_frames5` → `python scripts/ally_tails.py` → 빌드).

## 공통 프롬프트 (매 요청 앞에 붙이기)

> 첨부한 손그림 고양이 캐릭터의 애니메이션 스프라이트 시트를 그려줘.
> **스타일 규칙 (반드시 지킬 것):**
> - 아이가 매직펜으로 그린 듯한 굵고 살짝 삐뚤빼뚤한 검은 외곽선
> - 채색은 평평한 단색: 몸통 노란색(#F2C13C), 몸통에 진한 갈색(#7E5222) 짧은 줄무늬 획 여러 개
> - **얼굴 구조**: 큰 흰 원 2개가 나란히 겹친 주둥이(속은 흰색, 눈동자 그리지 말 것!),
>   주둥이 위 이음새에 작고 새까만 코, 그 위 머리에 아주 작은 점 눈 2개, 수염 양쪽 2~3가닥
> - 머리와 몸이 목 없이 하나로 붙은 뚱뚱한 달걀형, 가는 막대기 다리 3~4개, 위로 말린 통통한 꼬리
> - 배경 순수 흰색, 그림자·그라데이션·질감 없음
> - **모든 프레임에서 오른쪽을 본다**
> **시트 규격:**
> - 가로 4칸 × 세로 2칸 = 8칸 격자, 이미지 크기 1600×800
> - 1번 칸(왼쪽 위) = 옆으로 서 있는 기준 자세, 2~8번 칸 = 아래 지정한 동작의 연속 7프레임
> - 8칸 모두 몸 크기와 바닥선(발 위치)이 완전히 동일할 것. 칸 경계에 닿지 않게.

## 시트별 요청 (공통 프롬프트 뒤에 이어 붙이기)

1. **normal_idle**: "동작: 제자리 대기 춤. 정면을 보고 한 팔을 들어 좌우로 흔들며 몸을 살짝 씰룩이는 7프레임. 눈·주둥이 위치는 모든 프레임에서 같은 자리에 고정."
2. **normal_walk**: "동작: 걷기. 다리가 앞뒤로 교차하고 몸이 위아래로 살짝 출렁이는 옆모습 걷기 사이클 7프레임."
3. **normal_jump**: "동작: 점프. 웅크림 → 도약 → 공중(다리를 몸에 붙임) → 착지 순서의 7프레임."
4. **normal_attack**: "동작: 냥냥펀치. 화난 눈썹으로 웅크렸다가 앞발을 뻗으며 앞으로 튀어나가는 7프레임."
5~8. **laser_\***: 위 1~4와 동일하되 "이 고양이는 눈 자리에 초록색으로 꽉 찬 타원 고글을 썼다(첨부 원안의 레이저냥이 참고). 공격 시트에서는 고글에서 초록 광선이 나간다."

## 확인 체크리스트 (생성 결과 검사)
- [ ] 주둥이 원 안에 눈동자가 없다 (눈은 위쪽 작은 점 2개)
- [ ] 8칸 모두 같은 크기·같은 바닥선
- [ ] 모두 오른쪽을 본다
- [ ] 줄무늬는 갈색, 배경은 흰색
