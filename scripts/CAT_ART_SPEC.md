## 1. 가장 중요한 것 — 얼굴 구조 (지금 틀린 부분)

원안의 얼굴은 위에서부터 이렇게 쌓여 있다:

```
        ▲   ▲          ← 귀: 작은 빈 삼각형 2개 (머리 위, 오른쪽 치우침)
     ·      ·          ← 눈: 아주 작은 검은 점 2개  ★★★
        ▼              ← 코: 작고 꽉 찬 검은 삼각/하트, 주둥이 두 원이 만나는 이음새 '위'에 얹힘 ★★★
   ╭────╮╭────╮        ← 주둥이: 큼직한 원 2개가 나란히 겹침 (속은 흰색, 굵은 검은 선) ★★★
  ─┤    ├┤    ├─       ← 수염: 오른쪽 3줄, 왼쪽 2~3줄
   ╰────╯╰────╯
```

### 절대 틀리면 안 되는 3가지
1. **큰 겹친 원 2개 = 눈이 아니라 주둥이(볼/입)다.** 안에 눈동자를 그리지 마라.
   현재 스프라이트는 여기에 흰자+검은 눈동자를 그려 넣었다 → **완전히 잘못됨.**
2. **눈은 아주 작은 검은 점 2개.** 주둥이 위쪽 머리통에 콕콕 찍혀 있다.
   지름은 코 너비의 절반 정도. 이 "작은 눈 + 큰 주둥이" 대비가 귀여움의 핵심이다.
3. **코는 주둥이 두 원의 이음새 꼭대기에 얹힌 작고 새까만 삼각형.**
   주둥이 아래나 가운데가 아니라 **두 원이 맞닿는 지점의 위**다.

### 표정 변주 (원안 `cat5.png` / `cat4.png` 참고)
- 대기 중 눈 감기: 점 대신 위로 볼록한 `^` 짧은 호 2개
- 대기 중 혀: 주둥이 이음새 아래로 작은 분홍/빨강 혀
- 공격: 눈 위에 굵고 짧은 사선 눈썹 2개(`\ /`)를 얹어 화난 표정
- 죽음/기절: 눈이 `✕` 2개

## 2. 몸통 공통 규칙

- **머리와 몸이 하나의 뚱뚱한 달걀형 덩어리**다. 목이 없다. 오른쪽 40%가 얼굴 영역.
- **기본 방향은 오른쪽을 본다.** (게임에서 좌우반전으로 왼쪽을 만든다)
- 외곽선: 굵은 검은 매직 선. 자를 댄 듯 매끈하면 안 되고 **살짝 떨리는 손그림 선**.
- 채색: **색연필 해칭** — 짧은 사선 스트로크가 보이고, 외곽선까지 꽉 채우지 않고 군데군데 흰 종이가 비친다.
  줄무늬는 진한 갈색/주황 짧은 선 여러 개.
- **꼬리**: 몸 왼쪽(뒤)에서 위로 휘어 올라가는 통통한 갈고리(`⌒` 뒤집힌 J). 가는 선이 아니라 두께가 있는 덩어리.
- **다리**: 몸 아래로 삐져나온 가는 검은 직선 3~4개. 짧고 살짝 벌어짐. 발바닥 표현 없음.

## 4. 애니메이션 (원안 `cat4.png` / `cat5.png`)

원본 시트에 행별로 이미 그려져 있다. **그 포즈를 그대로 살릴 것.**

- **대기(idle)**: 숨쉬기(몸 세로로 살짝 눌렸다 펴짐), 눈 깜빡임(`^ ^`), 혀 내밀기, 꼬리 살랑.
- **이동(walk)**: 다리 교차 스트라이드, 몸통 위아래 바운스, 꼬리 흔들림.
- **점프(jump)**: ①웅크림 → ②공중(다리 몸 아래로 짧게 붙고 아래에 `ıı` 표시) → ③착지.
- **공격(attack)**: 화난 눈썹으로 웅크렸다가 앞으로 튀어나감. 레이저냥이는 고글에서 초록 광선 발사.

**중요**: 프레임끼리 몸집·바닥선이 흔들리면 애니메이션이 이상해 보인다.
모든 프레임을 **같은 몸 크기, 같은 바닥선**으로 그릴 것.

## 5. 산출물 규격 (기존 파이프라인 호환)

### 5-1. 단일 스프라이트
- 출력: `Plan/cat_sprites4/<이름>.png` (위 표의 리소스 이름에서 `cat_` 접두어 뺀 것 = 기존 `Plan/cat_sprites3` 파일명과 동일)
- 흰 배경 위에 그리고, 캐릭터는 캔버스 안에 여백을 두고 배치 (`scripts/cat_sprites.py`가 바깥 흰색을 투명 처리하고 잘라낸다)
- 충분히 크게(짧은 변 1000px 이상) 그린 뒤 저장 — 게임에서 130~220px로 줄여 쓴다

### 5-2. 애니메이션 시트
- 출력: `Plan/cat_frames3/<normal|laser>_<idle|walk|jump|attack>.png`
- **4열 x 2행 = 8칸** 격자
- **1번 칸(좌상단) = 기준 자세**(모든 시트 공통 동일 포즈), **2~8번 칸 = 그 동작의 7프레임**
  (`scripts/cat_anim2.py`가 1번 칸 몸 높이로 배율을 맞춘다)
- 각 칸 안에서 캐릭터가 칸 경계에 닿지 않게, 바닥선을 칸마다 동일하게

### 5-3. 변환 실행
```bash
python scripts/cat_sprites.py     # Plan/cat_sprites4 → drawable-nodpi/cat_*.png
python scripts/cat_anim2.py       # Plan/cat_frames3  → drawable-nodpi/anim_*.png
```
(두 스크립트의 `SRC_DIR`을 새 폴더로 바꿀 것)

## 6. 작업 순서 — **한 마리씩**

한 번에 다 그리지 말고 **한 마리 그리고 → 저장 → 원본과 나란히 비교 → 다음 마리** 순서로 진행한다.
`normal_cat`을 먼저 완성해서 얼굴 구조(작은 점 눈 / 큰 겹친 주둥이 / 이음새 위의 검은 코)를 확정한 뒤,
그 얼굴 함수를 나머지 냥이에 재사용한다.
